<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser query string → /admin → PostgREST | q, estado, tipo and pagina are attacker-controllable text that ends up in a database query |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-23 | Tampering | PostgREST filter injection through the search text | medium | mitigate | User text only goes through `.ilike()`/`.eq()` value parameters, never into a composed filter string (acceptance grep); % _ \ escaped and * removed; 100-character cap; db test with a literal "100%" |
| T-02-24 | Tampering | invalid estado/tipo/pagina parameters | low | mitigate | Enum membership check and integer clamp 1..10000 in `leerParametrosLista`; unit tests; e2e with tampered params returns 200 |
| T-02-25 | Denial of Service | huge page numbers / expensive counts | low | accept | Page clamped to 10000 and to the last real page; count exact is cheap at ~10-15 reservas/week (RESEARCH volume); revisit if volume grows |
| T-02-26 | Information Disclosure | filtered list for non-admins | high | mitigate | Unchanged: page `await requireAdmin()` + RLS admin policy; 02-02 customer-isolation db test stays in the suite |
| T-02-27 | Tampering (XSS) | search text echoed back into the input | low | mitigate | Rendered only as a React prop/value (escaped); no raw HTML rendering |
</threat_model>
