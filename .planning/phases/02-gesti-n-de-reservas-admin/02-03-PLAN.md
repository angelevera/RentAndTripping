|-----------|----------|-----------|----------|-------------|-----------------|

| T-02-14 | Tampering | tipo / cross-type fields | medium | mitigate | tipo enum in the discriminated union; unknown keys stripped; DB check detalle.tipo = tipo (02-01); e2e "crucero" and "hotel + pnr" cases |
| T-02-15 | Denial of Service | oversized text / lists in detalle | low | mitigate | zod length limits, 20-name cap, 1-50 people; DB size check ≤ 16 KB (02-01) |
| T-02-16 | Tampering | price manipulation (0, negative, huge, locale tricks) | medium | mitigate | Comma normalised, positive, ≤ 10,000,000 in zod; DB check precio ≥ 0 and numeric(12,2) bound |
| T-02-01 | Elevation of Privilege | crearReserva | high | mitigate | Unchanged from 02-01: `await requireAdmin()` first + RLS; 02-01 anonymous/customer e2e cases stay in the suite |
