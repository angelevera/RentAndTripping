## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /login Server Action | Untrusted form input, possibly submitted without JavaScript or crafted by hand |
| query string → /login page | Untrusted `motivo` parameter |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-25 | Information Disclosure | login error messages (account enumeration) | medium | mitigate | One identical message for unknown email and wrong password; both cases are tested (Task 2) |
| T-01-26 | Tampering | bypassing client-side validation | medium | mitigate | esquemaLogin.safeParse runs in the Server Action; a no-JS malformed-email test proves the server rejects it (Task 2) |
| T-01-27 | Spoofing (brute force) | signInWithPassword | low | transfer | Supabase Auth's built-in rate limiting (CONTEXT discretion: defaults, no custom lockout); 429 mapped to a Spanish message |
| T-01-28 | Tampering (open redirect / reflected content) | motivo query param, post-login redirect | low | mitigate | Redirect targets are fixed paths ('/admin'); motivo is only compared to a constant and never rendered; no raw-HTML rendering (grep criterion) |
</threat_model>
