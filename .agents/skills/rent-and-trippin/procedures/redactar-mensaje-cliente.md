# Procedimiento: borrador de mensaje al cliente

Prepara mensajes para que el operador los revise y envíe por el canal que decida. No envíes mensajes ni contactes a terceros.

1. Define el propósito: pedir información, compartir una cotización, informar un cambio o recordar una fecha.
2. Usa exclusivamente los datos confirmados en la conversación o en los archivos pertinentes.
3. Si falta un precio, disponibilidad, fecha límite, estado de pago/proveedor o política comercial, pregunta antes de afirmar algo sobre ello.
4. No escribas que una reserva o pago está confirmado salvo que el operador lo haya verificado explícitamente.
5. Redacta en español claro, cálido y conciso, adecuado para WhatsApp o Instagram.
6. Devuelve el texto como borrador y destaca campos pendientes para revisión.
