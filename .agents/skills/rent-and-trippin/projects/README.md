# Proyectos de trabajo

Usa una carpeta por iniciativa o tarea larga, no una carpeta con datos identificables por cliente. No copies comprobantes, documentos de viaje, datos de pago ni secretos a este directorio.

Duplica `TASK-template.md` para registrar un trabajo que cruce sesiones. Mantén el estado actualizado y elimina de la nota los detalles innecesarios antes de compartirla.
