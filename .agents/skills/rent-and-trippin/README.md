# Agente Rent & Trippin

Habilidad de proyecto compartida para Claude Code y Codex. El punto de entrada es `SKILL.md`; el contexto, procedimientos, memoria y plantillas viven junto a él para mantenerlos versionados con el repositorio.

## Activarla

- En Claude Code, invoca `/rent-and-trippin` o pide una tarea relacionada con el producto/agencia; revisa `/skills` si no aparece en la lista.
- En Codex, pide que use la habilidad `rent-and-trippin` para una tarea del proyecto. Esta habilidad aporta el contexto específico del negocio y complementa las instrucciones generales del repositorio.

## Mejorarla con el uso

1. Prueba una tarea concreta y revisa el resultado manualmente.
2. Explica las correcciones necesarias al agente.
3. Confirma cuáles son reglas generales y cuáles aplican solo a ese caso.
4. Actualiza el procedimiento o la memoria únicamente con las reglas confirmadas.

Este agente organiza y prepara trabajo. No está conectado a WhatsApp, Instagram, proveedores ni pagos y no es un bot desplegado para atender clientes automáticamente.
